# 🧾 Kept - Receipt & Newspaper Photo Booth (ตู้ถ่ายรูปใบเสร็จ & หนังสือพิมพ์วินเทจ)

แอปพลิเคชันตู้ถ่ายรูป Photo Booth เทรนด์ใหม่ยอดนิยมสำหรับคาเฟ่, งานอีเวนต์ และพื้นที่ไลฟ์สไตล์ (สไตล์ตู้ใบเสร็จ *Keep Your Receipt* และตู้หนังสือพิมพ์วินเทจ *Songwat Times*) รองรับทั้งระบบ **iPadOS / iOS** และ **Android Tablet**

---

## 📸 การเชื่อมต่อกล้องภายนอก & การปรับแต่งภาพ (External Cameras & Calibration)

ในโหมดตั้งค่า (Admin Mode: PIN `1234`) สามารถเพิ่ม สลับอุปกรณ์กล้องภายนอก และปรับแต่งค่าพารามิเตอร์คุณภาพของกล้องได้อย่างละเอียด:

### 1. อุปกรณ์กล้องที่รองรับ (Supported Camera Hardware)
* **กล้องเว็บแคม (USB Webcams)**: Logitech Brio 4K, Razer Kiyo Pro, Elgato Facecam ผ่านพอร์ต USB 3.0 UVC
* **กล้อง Mirrorless & DSLR**: Sony Alpha A7 / A6400, Canon EOS R / 200D II, Nikon Z ผ่าน USB Tethering หรือ HDMI UVC Video Capture Card 4K
* **กล้องดิจิทัลคอมแพค (Digital Compact Cameras)**: Ricoh GR, Canon G7X, Fuji X100
* **กล้องโพลารอยด์ (Instant Cameras)**: Polaroid Now+, Fujifilm Instax Link ผ่าน Bluetooth / Direct Wi-Fi
* **กล้องในตัวเครื่อง (Built-in Tablet Camera)**: กล้องหน้า Ultra-Wide พร้อมระบบจัดกึ่งกลางอัตโนมัติ

### 2. ฟังก์ชันปรับแต่งภาพแบบ Real-time (Camera Calibration Parameters)
* ☀️ **แสง (Exposure / Brightness)**: ปรับชดเชยแสง -100% ถึง +100% (หรือ EV -3 ถึง +3)
* 🔍 **ความคมชัด (Sharpness / Clarity)**: ปรับความคมชัดของขอบเส้น 0% ถึง 200%
* 🌗 **คอนทราสต์ (Contrast)**: ปรับคอนทราสต์ 50% ถึง 200% (เพิ่มความเปรียบต่างแสง-เงา ซึ่งสำคัญมากสำหรับการพิมพ์สลิปความร้อนแบบ Dithering และหนังสือพิมพ์ Halftone)
* 🌡️ **ไวท์บาลานซ์ (White Balance)**: เลือก Preset (Auto, Daylight, Warm Tungsten, Fluorescent) หรือปรับอุณหภูมิสีเคลวิน (2500K - 8500K)
* 🎨 **สี / ความอิ่มตัว (Saturation & Tone)**: ปรับความสดของสีได้ตั้งแต่ 0% (ขาวดำ Monochrome 100%) จนถึง 200% (Vivid Pop)
* **Live Preview**: มีหน้าต่างแสดงผลจำลองตามค่าที่ปรับแบบเรียลไทม์ภายในแอดมินพาเนล

## 🖼️ ระบบจัดการเฟรม & เครื่องพิมพ์

* **อัปโหลดเฟรม & รูปแบบหนังสือพิมพ์ (Admin Only)**:
  * เพิ่มและอัปโหลดไฟล์ภาพ PNG กรอบรูปโปร่งใส
  * กำหนดชื่อสไตล์, หัวหนังสือพิมพ์, หรือชื่อร้านบนสลิปใบเสร็จ
  * บันทึกแล้วตัวเลือกจะเปิดให้ลูกค้าหน้าตู้ใช้งานได้ทันที
* **ระบบเครื่องพิมพ์ความร้อน (Thermal ESC/POS)**:
  * ย้ายระบบและสถานะเครื่องพิมพ์มาไว้ในโหมดการตั้งค่าทั้งหมด หน้าหลักลูกค้าจะไม่มีปุ่มเครื่องพิมพ์ให้รบกวนสายตา
  * รองรับม้วนกระดาษความร้อน 80mm, 58mm และม้วนสติกเกอร์ความร้อน
  * เช็กปริมาณกระดาษคงเหลือ พร้อมปุ่มทดสอบพิมพ์สลิป (Test Print)

## 🏦 ระบบผูกบัญชีธนาคาร & ดำเนินการต่ออัตโนมัติ (Thai Banks & PromptPay Auto-Advance)

ระบบรองรับการผูกบัญชีธนาคารชั้นนำในประเทศไทยและระบบพร้อมเพย์สำหรับการรับชำระเงินของตู้ Photo Booth ในโหมดตั้งค่า (Admin):

### 1. รายชื่อธนาคารที่รองรับ (Supported Thai Banks)
* 🟢 **ธนาคารกสิกรไทย (KBANK)**: ผูกบัญชีกระแสรายวัน/ออมทรัพย์ หรือ K-Payment Gateway / K API
* 🟣 **ธนาคารไทยพาณิชย์ (SCB)**: SCB Open Banking API (Biller ID / Merchant QR)
* 🔵 **ธนาคารกรุงไทย (KTB)**: Krungthai NEXT Open API / Paotang Merchant
* 🔷 **ธนาคารกรุงเทพ (BBL)**: BBL iPay / BBL Merchant QR
* 🟡 **ธนาคารกรุงศรีอยุธยา (BAY)**: Krungsri Merchant QR
* 🔴 **ธนาคารทหารไทยธนชาต (TTB)**: ttb smart shop / Open API
* 🌸 **ธนาคารออมสิน (GSB)** & 🌾 **ธ.ก.ส. (BAAC)**
* ⚡ **ระบบพร้อมเพย์ AnyID (PromptPay National Standard)**: เลขบัตรประชาชน/นิติบุคคล 13 หลัก, เบอร์โทรศัพท์ 10 หลัก, หรือ e-Wallet ID

### 2. กระบวนการทำงานอัตโนมัติ (Automated Real-time Flow)
1. **Dynamic Thai QR EMVCo Generation**: เมื่อลูกค้าเลือกแพ็กเกจ (เช่น ฿89 หรือ ฿140) แอปจะสร้าง Dynamic QR Code ตามมาตรฐาน EMVCo ที่ฝังยอดเงินและ Reference ID ของตู้โดยอัตโนมัติ
2. **Branded Visual Experience**: หน้าจอชำระเงินจะเปลี่ยนธีมสี โลโก้ และข้อมูลบัญชีตามธนาคารที่แอดมินตั้งเป็นบัญชีหลัก (เช่น แถบสีเขียวสำหรับกสิกร, สีม่วงสำหรับไทยพาณิชย์)
3. **Real-time Webhook & Instant Auto-Advance**: ทันทีที่ลูกค้าสแกนจ่ายผ่านแอปธนาคารใดก็ได้ สัญญาณ Webhook หรือ Callback จะส่งเข้าเครื่อง และระบบจะ:
   * เล่นเสียงสัญญาณ Chime แจ้งเตือนการรับเงินสำเร็จ
   * แสดงแบนเนอร์ **"ชำระเงินสำเร็จ (Paid Success)"**
   * **เปลี่ยนหน้าไปยังการนับถอยหลังถ่ายภาพ (Countdown & Capture) โดยอัตโนมัติทันที** โดยที่ลูกค้าไม่ต้องแตะปุ่มใดๆ บนหน้าจอ

## 🖼️ เมนูเฟรม & การดึงข้อมูลจาก Google Drive (Frame Gallery & Drive Sync)

ระบบมาพร้อมหน้าเมนู **Frame Management & Gallery** ซึ่งเข้าถึงได้ทั้งจากปุ่ม `Frames` บนแถบเมนูลอย และในหน้าตั้งค่า Admin:

### 1. แถบควบคุมเมนูเฟรม (Toolbar Controls)
* ☁️ **ดึงข้อมูลจาก Google Drive**: เชื่อมต่อไปยังโฟลเดอร์ `1OCBCMHKNRdkMOZq4U9uGbvbg8wNBCTih/frames` เพื่อดึงรายชื่อไฟล์กรอบรูป PNG และเทมเพลตหนังสือพิมพ์ที่มีบนคลาวด์ พร้อมให้ผู้ใช้กดติ๊กเลือกและนำเข้าสู่ระบบได้ทันที
* ➕ **เพิ่มเฟรมใหม่ (Add Custom Frame)**: สามารถสร้างเฟรมใหม่ กำหนดประเภทเลย์เอาต์ (สลิปใบเสร็จ 80mm, หนังสือพิมพ์วินเทจ, โฟโต้สตริป 2x6", ภาพตาราง 4x6"), ชื่อสไตล์, และพาดหัว
* 🗑️ **ลบเฟรม (Delete Frame)**: รองรับทั้งการกดลบเฉพาะเฟรมที่ต้องการ และโหมดเลือกลบหลายรายการพร้อมกัน (Bulk Delete)

### 2. การแสดงรายการเฟรมในระบบ (System Frame List)
* แสดงการ์ดข้อมูลของแต่ละเฟรม พร้อม Badge ระบุประเภทเลย์เอาต์ และแหล่งที่มา (`System Preset` หรือ `Google Drive Synced ☁️`)
* ลูกค้าหรือแอดมินสามารถกดปุ่ม **"เลือกใช้สไตล์นี้"** เพื่อเริ่มเซสชันถ่ายภาพตามสไตล์นั้นได้ทันที
